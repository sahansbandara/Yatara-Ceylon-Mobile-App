# Mobile Viva Checklist

## Demo Flow

- [ ] Open mobile app.
- [ ] Register a new traveler.
- [ ] Login.
- [ ] Browse packages from API.
- [ ] Open package details.
- [ ] Create a booking.
- [ ] Show booking in My Bookings.
- [ ] Login as admin/staff.
- [ ] Add/edit/delete a package.
- [ ] Upload an image.
- [ ] Update booking status.
- [ ] Show MongoDB record.
- [ ] Show hosted backend URL.

## Required Documents

- [ ] Problem statement.
- [ ] Architecture diagram: Mobile -> Express API -> MongoDB.
- [ ] Database schema diagram.
- [ ] API endpoint table.
- [ ] Team responsibility breakdown.
- [ ] Test case table from `docs/MOBILE-TEST-CASES.md`.
- [ ] Screenshots.
- [ ] Test cases.
- [ ] Deployment proof.

## Common Viva Questions

- Why not WebView?
- How does JWT auth work in mobile?
- How does the app protect admin routes?
- How does the mobile app connect to hosted backend?
- How is image upload handled?
- What is each member's CRUD entity?
- How does MongoDB store the records?
