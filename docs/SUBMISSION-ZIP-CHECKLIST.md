# SE2020 Submission ZIP Checklist

Source reviewed: `SE2020 Assignment Submission Guidelines.pdf`.

## Important Rule

Do not include source code in the LMS ZIP. The ZIP must contain documentation only. All coding must be available in GitHub.

## Required ZIP Name

```text
WDDS01_Group_<GroupNumber>_Submission.zip
```

## Required Folder Structure

```text
SE2020_Group_<GroupNumber>_Submission/
├── Problem_Statement.pdf
├── System_Architecture_Diagram.png
├── Database_Schema_Diagram.png
├── API_Endpoint_Table.pdf
├── Team_Responsibility.pdf
└── README.txt
```

## GitHub Repository Requirement

The GitHub repository must include:

- `frontend/`
- `backend/`
- proper project structure

This repository follows that requirement:

```text
frontend/    React Native Expo mobile app
backend/     Node.js + Express API
docs/        Assignment documentation and diagrams
```

## README.txt Requirement

The ZIP `README.txt` must include:

- GitHub repository link
- Group number
- Six team members with IDs, names, and modules
- Backend deployment URL

Use `docs/submission/README.txt` as the template.

## Before Uploading

- [ ] Export problem statement as `Problem_Statement.pdf`.
- [ ] Export architecture diagram as `System_Architecture_Diagram.png` or `.pdf`.
- [ ] Export database schema as `Database_Schema_Diagram.png` or `.pdf`.
- [ ] Export API endpoint table as `API_Endpoint_Table.pdf`.
- [ ] Export team responsibility table as `Team_Responsibility.pdf`.
- [ ] Fill group number in `README.txt`.
- [ ] Fill hosted backend URL in `README.txt`.
- [ ] Confirm GitHub link opens publicly.
- [ ] Confirm ZIP contains no source code.
