# Yatara Ceylon Mobile Documentation

This folder contains the assignment evidence for the React Native + Express + MongoDB mobile system.

## Main Documents

| File | Purpose |
| --- | --- |
| `MOBILE-CONVERSION-PLAN.md` | Project scope, architecture, and implementation order |
| `MOBILE-API.md` | Express API endpoint reference |
| `MOBILE-DEPLOYMENT-STEPS.md` | Step-by-step Render/Railway + MongoDB Atlas + Expo setup |
| `MOBILE-TEAM-BREAKDOWN.md` | Six-member module ownership |
| `MOBILE-TEST-CASES.md` | Backend, mobile, upload, auth, and deployment tests |
| `MOBILE-VIVA-CHECKLIST.md` | Demo flow and viva preparation |
| `MOBILE-FINAL-REPORT.md` | Report-ready project summary |
| `WMT-ASSIGNMENT-COMPLIANCE.md` | Mapping from assignment requirements to implementation |
| `SUBMISSION-ZIP-CHECKLIST.md` | SE2020 ZIP packaging checklist |

## Member Files

The `yatara_member_md_files/` folder contains one document per group member. Each file explains the member's entity, backend files, mobile screens, API routes, testing evidence, and viva focus.

## Diagrams

The `diagrams/` folder contains HTML diagram assets for architecture and database schema. Export these as screenshots or PDF images for the final report.

## Submission ZIP

The `submission/README.txt` file is the README template for the LMS documentation ZIP. Fill in the final group number and hosted backend URL before packaging.
