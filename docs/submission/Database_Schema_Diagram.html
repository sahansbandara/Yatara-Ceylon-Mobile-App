Schema Design Patterns

  • Soft Deletes — All models use isDeleted: Boolean + deletedAt: Date instead of permanent removal
  • Timestamps — All models use { timestamps: true } for auto createdAt / updatedAt
  • Embedded Sub-Documents — Package.itinerary[] stores day-by-day plans as nested sub-docs (no separate collection)
  • Pre-Save Hook — Booking auto-generates bookingNo (YC-MOB-01XXX) and calculates remainingBalance
  • Enum Constraints — Role (5 values), Vehicle type (5), Partner type (4), Booking status (8) restricted via Mongoose enum
  • Compound Index — Package has { type: 1, style: 1 } index for fast filtered queries
